# SocialMarket — учебный интернет-магазин

Учебный многостраничный сайт по дисциплине «Фронтенд и бэкенд разработка». Тема проекта — каталог демонстрационных аккаунтов социальных сетей Instagram, TikTok, Telegram, Snapchat и WhatsApp.

Карточки, количество подписчиков и цены используются только как учебные примеры. Реальной продажи аккаунтов, сервера и платёжной системы в проекте нет.

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

## Страницы

- `index.html` — главная страница с описанием проекта, преимуществами и популярными карточками.
- `catalog.html` — каталог из шести карточек и статический блок категорий.
- `product.html` — подробная карточка товара с описанием, ценой и таблицей характеристик.
- `order.html` — форма оформления заявки.
- `contacts.html` — контактная информация и ссылки на разделы сайта.

## БЭМ-структура проекта

Основные блоки и элементы:

- `site-header`, `site-nav` — шапка и навигация;
- `site-logo` — логотип;
- `breadcrumbs` — хлебные крошки;
- `hero` — первый экран главной страницы;
- `section`, `section-heading` — разделы и их заголовки;
- `products-grid`, `product-card` — сетка и карточки товаров;
- `catalog-layout`, `catalog-filters`, `category-list` — макет и блок категорий каталога;
- `product-detail`, `specifications` — подробная карточка и характеристики товара;
- `order-form` — форма заявки;
- `order-dialog` — модальное окно;
- `button` — кнопки с модификаторами;
- `site-footer` — подвал сайта.

Элементы записываются через `block__element`, а варианты оформления — через `block--modifier` или `block__element--modifier`.

## Используемые технологии

- HTML5 — семантическая структура страниц, навигация, карточки, таблица и формы.
- CSS3 — внешний файл `css/style.css`, переменные `:root` и `var()`, состояния `:hover`, `:focus-visible`, `:disabled`, Flexbox, Grid и позиционирование.
- JavaScript — открытие и закрытие `<dialog>`, выбор товара для заявки и демонстрационная проверка форм.
- Git и GitHub — контроль версий и публикация через GitHub Pages.

## Самостоятельные доработки

- Сделано отдельное оформление SocialMarket с карточками для пяти социальных платформ.
- В карточках каталога добавлены бейджи, краткие характеристики и переходы к подробному описанию.
- Страница товара получает выбранный товар из параметра адреса `?item=...` и обновляет описание, цену и таблицу.
- В модальном окне выбранный товар записывается в скрытое поле формы.
- Для форм добавлены подписи полей, обязательные значения и проверка браузером; сообщение об успешной проверке выводится в демонстрационном режиме.

## Как открыть сайт

1. Откройте папку проекта `kr1-html-css-shop` в Visual Studio Code.
2. Откройте `index.html` в браузере или запустите его через расширение Live Server.
3. Перейдите по меню на остальные страницы и проверьте формы и модальное окно.

Форма не отправляет данные на сервер. После успешной проверки браузером показывается демонстрационное сообщение. Фильтры каталога представлены статическим макетом.
